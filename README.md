# 아침 운세 (피클용)

피클이 읽고 매일 아침 맞춤 운세를 보내기 위한 기초 이론 저장소입니다.

- `피클 아침 운세 프롬프트.md` : 피클에게 넘기는 전용 프롬프트
- `docs/` : 해석 기준 문서 (천간지지오행, 십성·12운성, 합충형파해, 용신 판단, 운 보는 법)
- `간지표/` : 세운·월운·일운 표 (2026-01-01 ~ 2030-12-31, 한국 시간 기준, 점마Pro 만세력 엔진으로 계산)
  - `일운.csv` 날짜별 세운·월운·일운 / `세운.md` 입춘 시각 / `월운.md` 절기 시각

개인 원국과 대운은 이 저장소에 넣지 않습니다.
