# 03. 합·충·형·파·해

## 천간
| 구분 | 조합 |
|---|---|
| 천간합 | 갑기(토) · 을경(금) · 병신(수) · 정임(목) · 무계(화) |
| 천간충 | 갑경 · 을신 · 병임 · 정계 (무기는 충 없음) |

- 합은 끌림·협력·묶임. 합이 되어 오행이 바뀌는지(화) 아닌지(합이불화)는 월지와 주변 기운이 도울 때만 화한다. 확신 없으면 "묶여서 본래 역할이 약해짐" 정도로만 말한다.

## 지지
| 구분 | 조합 |
|---|---|
| 육합 | 자축(토) · 인해(목) · 묘술(화) · 진유(금) · 사신(수) · 오미(화/토) |
| 삼합 | 신자진(수) · 해묘미(목) · 인오술(화) · 사유축(금) |
| 방합 | 인묘진(목) · 사오미(화) · 신유술(금) · 해자축(수) |
| 충 | 자오 · 축미 · 인신 · 묘유 · 진술 · 사해 |
| 형 | 인사신(무은지형) · 축술미(지세지형) · 자묘(무례지형) · 진진/오오/유유/해해(자형) |
| 파 | 자유 · 축진 · 인해 · 묘오 · 사신 · 미술 |
| 해 | 자미 · 축오 · 인사 · 묘진 · 신해 · 유술 |

## 강도 (센 순서)
충 > 형 > 합(삼합·육합) > 해 > 파
- 충: 부딪힘·변동·이동·갈등. 충이 용신을 치면 크게 흔들리고, 기신을 치면 오히려 풀리기도 한다.
- 형: 압박·시비·수술·법적 문제. 단, 오늘 풀이에서는 겁주지 않고 "조심할 장면"으로만 말한다.
- 합: 인연·협력·묶임·결정. 용신과 합하면 좋고, 기신과 합하면 기신이 커진다.
- 해·파: 은근한 방해, 약속 틀어짐, 사소한 손실.

## 해석 시 순서
1. 오늘의 간지(일운)가 내 원국·현재 대운의 어느 자리(년·월·일·시)와 만나는지 확인한다.
2. 어느 자리인지에 따라 영역이 달라진다.
   - 년지: 외부·집안·먼 인연 / 월지: 직장·사회·일 / 일지: 나·배우자·연애 / 시지: 자녀·미래·말년
3. 충·합이 용신에 닿는지 기신에 닿는지 판단한다.
4. 여러 개가 겹치면 가장 센 것 하나를 중심으로 설명하고, 나머지는 한 줄로 덧붙인다.
