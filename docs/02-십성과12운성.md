# 02. 십성·12운성

## 십성 판별 (일간 기준)
| 관계 | 음양 같음 | 음양 다름 |
|---|---|---|
| 나와 같은 오행 | 비견 | 겁재 |
| 내가 생해주는 오행 | 식신 | 상관 |
| 내가 극하는 오행 | 편재 | 정재 |
| 나를 극하는 오행 | 편관(칠살) | 정관 |
| 나를 생해주는 오행 | 편인 | 정인 |

예) 일간이 갑(양목)이면 → 병(양화)=식신, 정(음화)=상관, 무(양토)=편재, 기(음토)=정재, 경(양금)=편관, 신(음금)=정관, 임(양수)=편인, 계(음수)=정인, 갑=비견, 을=겁재.

## 십성의 뜻
| 십성 | 키워드 | 오늘의 장면 예 |
|---|---|---|
| 비견 | 나·동료·자존심·독립 | 동료와 협력 또는 경쟁, 내 방식 고집 |
| 겁재 | 경쟁자·분산·승부욕 | 지출·경쟁·돈 나눠 쓰기, 친구 부탁 |
| 식신 | 표현·여유·먹거리·재능 | 편안한 식사, 아이디어, 창작, 부드러운 말 |
| 상관 | 말·재능·반항·변화 | 말실수·비판, 날카로운 표현, 규칙 거스르기 |
| 편재 | 큰돈·사업·유동 재물·활동 | 거래·영업·투자 기회, 외부 활동 |
| 정재 | 안정 수입·저축·성실 | 월급·정산, 꼼꼼한 관리, 현실적 선택 |
| 편관 | 압박·도전·권위·긴장 | 갑작스런 업무, 상사의 압박, 승부 |
| 정관 | 규칙·직장·명예·책임 | 공식적 일정, 평가, 약속·질서 |
| 편인 | 직관·특이한 공부·고독 | 혼자 생각, 영감, 걱정·예민함 |
| 정인 | 학업·보호·문서·어머니 | 계약서·시험·귀인의 도움, 배움 |

## 연애·재물·건강으로 번역하는 기준
- 남성의 배우자 별: 재성(정재=아내, 편재=연인·이성 인연). 관성은 직장·자식.
- 여성의 배우자 별: 관성(정관=남편, 편관=연인·이성 인연). 식상은 자식·표현.
- 배우자궁: 일지(일주의 지지). 일지에 합이 들어오면 관계 진전·만남, 충이 들어오면 갈등·변동.
- 재물: 재성의 움직임(편재=움직이는 돈, 정재=고정 수입)과 식상이 재성을 낳는 흐름. 겁재·비견이 강하면 지출·분산.
- 일·명예: 관성과 인성. 관성이 오면 책임·평가, 인성이 오면 문서·도움.
- 건강: 해당 오행이 과다하거나 부족한 장부, 충·형이 걸리는 오행의 장부(01번 문서 표).

## 12운성
일간이 각 지지에서 얻는 기운의 강약.

순서: 장생 → 목욕 → 관대 → 건록 → 제왕 → 쇠 → 병 → 사 → 묘 → 절 → 태 → 양

| 일간 | 장생 위치 | 방향 | 건록 | 제왕 |
|---|---|---|---|---|
| 갑 | 해 | 순행 | 인 | 묘 |
| 을 | 오 | 역행 | 묘 | 인 |
| 병·무 | 인 | 순행 | 사 | 오 |
| 정·기 | 유 | 역행 | 오 | 사 |
| 경 | 사 | 순행 | 신 | 유 |
| 신 | 자 | 역행 | 유 | 신 |
| 임 | 신 | 순행 | 해 | 자 |
| 계 | 묘 | 역행 | 자 | 해 |

- 순행: 장생에서 시작해 지지 순서대로 진행. 역행: 거꾸로.
- 힘 있는 단계: 장생·관대·건록·제왕. 힘이 약한 단계: 병·사·묘·절. 새 출발의 단계: 태·양.
- 해석은 보조 용도다. 오늘의 풀이에서는 합충과 용신 여부를 먼저 보고, 12운성은 강약을 보강할 때만 쓴다.
